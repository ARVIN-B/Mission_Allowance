# راهنمای راه‌اندازی کامل دستیار حق مأموریت در Open WebUI

## ۱. ترتیب نصب اجزا در پنل مدیریت Open WebUI

### گام ۱: بارگذاری Skill
1. به مسیر **`Workspace → Skills`** بروید.
2. از منوی کنار دکمه Create گزینه **`Import`** را انتخاب کرده و فایل **`mission-allowance-calculator.skill`** را بارگذاری کنید. *(این فایل شامل `SKILL.md` و پوشه `references/` است.)*
3. روی Skill کلیک کنید و در بخش **Access Control** دسترسی **Read** را برای گروه پرسنل (یا Public) فعال کنید تا هنگام اتصال به مدل برای کاربران حذف نشود.

### گام ۲: ایجاد Knowledge Base
1. به مسیر **`Workspace → Knowledge → Create`** بروید و یک مجموعه با نام مثلاً `HR_Mission_Policy_1405` بسازید.
2. هر ۴ فایل پوشه `knowledge/` را بارگذاری کنید:
   - `01_policy_rules.md`
   - `02_rates_and_coefficients.md`
   - `03_cities_distances.md`
   - `04_calendar_1405_holidays.md`
3. دسترسی **Read** را برای گروه پرسنل تنظیم کنید.
4. *(توصیه برای جست‌وجوی دقیق فارسی)* در **`Admin Panel → Settings → Documents`** از یک مدل Embedding چندزبانه (مثل `bge-m3` یا API چندزبانه) استفاده کنید.

### گام ۳: نصب Python Tool
1. به مسیر **`Workspace → Tools → +`** بروید.
2. محتوای فایل **`tool/mission_calculator_tool.py`** را کپی و ذخیره کنید.
3. از آیکون چرخ‌دنده (**Valves**) ابزار می‌توانید هر سال نرخ‌های غذا/اسکان، نرخ کیلومتری، ضریب تعطیلات و حالت نمایش فرم گرافیکی (`render_rich_html_form`) را بدون تغییر کد ویرایش کنید.
4. دسترسی **Read / Use** ابزار را برای گروه پرسنل فعال کنید.

### گام ۴: ساخت مدل نهایی (`Workspace → Models`)
1. یک Model Preset جدید با نام **«دستیار محاسبه حق مأموریت»** روی مدل API دلخواه خود (مدلی با پشتیبانی قوی از Native Function Calling مثل GPT-4.1 / GPT-5 / Claude Sonnet / Gemini Pro) بسازید.
2. **System Prompt پیشنهادی (کوتاه و دقیق):**
```text
تو دستیار رسمی محاسبه حق مأموریت و هزینه‌های جانبی شرکت هستی.
همیشه مطابق مهارت mission-allowance-calculator عمل کن:
1) در بدو مصاحبه کد پرسنلی و اطلاعات ناقص را کوتاه و شماره‌دار بپرس (مبدأ پیش‌فرض: اصفهان).
2) پیش از محاسبه، حتماً خلاصه ورودی‌ها را همراه با تعطیلات تقویم ۱۴۰۵ به کاربر نشان بده و تأیید بگیر.
3) پس از تأیید، فقط از ابزار calculate_mission_report استفاده کن و در پاسخ نهایی فقط فرم گزارش جدول‌بندی‌شده را بدون هیچ توضیح اضافه‌ای نمایش بده.
```
3. **تنظیمات کلیدی مدل:**
   - `Advanced Params → Function Calling`: حتماً روی **`Native`** باشد.
   - `Capabilities / Builtin Tools`: گزینه‌های **`Skills`** و **`Knowledge Base`** روشن، و **`Web Search`** خاموش باشد.
   - `Skills`: اتصال `mission-allowance-calculator`.
   - `Knowledge`: اتصال `HR_Mission_Policy_1405`.
   - `Tools`: تیک ابزار `محاسبه‌گر حق مأموریت و هزینه‌های جانبی (نسخه ۱۴۰۵)`.
   - `Access Control`: دسترسی **Read Only** برای کاربران سازمانی.

4. **پیشنهادهای شروع گفتگو (Prompt Suggestions):**
   - `محاسبه حق مأموریت تک‌مرحله‌ای`
   - `محاسبه حق مأموریت چندمرحله‌ای (چندمقصده)`
   - `محاسبه حق مأموریت گروهی همراه با مافوق`
   - `استعلام سقف غذا، اسکان و تعطیلات سال ۱۴۰۵`
